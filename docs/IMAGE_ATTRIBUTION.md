# Image attribution

The app loads these original SVG illustrations from Wikimedia Commons and displays them without redrawing them:

- **Itachi Uchiha's Mangekyō Sharingan** — file by ShounenSuki: https://commons.wikimedia.org/wiki/File:Mangekyou_Sharingan_Itachi.svg
- **Uchiha clan fan symbol** — file by Chatsam: https://commons.wikimedia.org/wiki/File:Symbole_Uchiwa.svg

Both file pages list Creative Commons Attribution-ShareAlike (CC BY-SA) licensing options. Review the individual source pages for the applicable license terms before redistributing modified artwork. The images are fetched from Wikimedia's upload host at runtime; internet access is needed to load them initially.
