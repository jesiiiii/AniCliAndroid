## ماذا يعمل في هذه النسخة؟

- **مصدر حقيقي مدمج بلا وسيط**: التطبيق يستخدم واجهة تطبيق Anime Slayer الرسمية المنشورة (anslayer.com) بنفس مسار المصدر المفتوح **ani-cli-arabic**، ويحلّ قنوات CDN الأولية عبر نفس آلية فك التشفير (seed + AES-ECB + RNCryptor v3)، إضافة إلى خوادم المجموعات (multi arrays) مثل OK.ru وMp4Upload وgoodstream.
- **بلا إعداد يدوي**: لا توجد شاشة إدخال API key أو رابط خادم. كل الأسرار المستخدمة عامة ومحفوظة في مستودع ani-cli-arabic (اخترها المصدر الأصلي علنياً)، ولا شيء خاص برفعته.
- **الصفحة الرئيسية**: أحدث الحلقات، الأكثر مشاهدة، الأعلى تقييماً — كلها من بيانات المصدر الحقيقية، مع صور أغلفة وتقييمات.
- **البحث الحقيقي**: بحرّي، مع تأخير اختيار 450 ملّي ثانية، ورسائل عربية عند عدم وجود نتائج أو فشل الاتصال، وإعادة محاولة صريحة.
- **تفاصيل الأنمي والحلقات**: عنوان عربي وإنجليزي، تقييم، تصنيفات، وصف، وقائمة حلقات مرقّمة مرتبة.
- **مشغّل مدمج**: ExoPlayer (Media3)، اختيار جودة تلقائي بعد التحقق من أن الرابط يعيد فيديو حقيقياً (تمريرة Range أصغر 1KB وتفحّص Content-Type)، أزرار تشغيل/إيقاف، ±10 ثوانٍ، سرعات 0.5x إلى 2x، ملء الشاشة الأفقي، شريط تقدم، وإعادة محاولة عند انقطاع البث.
- **واجهة عربية كاملة RTL** بتصميم مادي حديث، وحالات تحميل وخطأ وفارغة واضحة.

## البناء والتشغيل

```bash
./gradlew :app:testDebugUnitTest   # اختبارات الوحدة
./gradlew :app:assembleRelease     # بناء نسخة التثبيت
```

يوجد ملف GitHub Actions يبني APK تلقائياً على كل دفعة للفرع الرئيسي ويحفظه كـ Artifact، ويرفقه على Release جديد.

## ماذا اختُبر فعلياً داخل بيئة التطوير؟

التحقق تم على مستوى واجهة المصدر نفسها (نفس الطلبات التي يقوم بها التطبيق مباشرة):

| المسار | النتيجة |
| --- | --- |
| بحث "naruto" عامل + تخزين `Client-Id`/`Client-Secret` | 10688 بايت JSON صالح مع نتائج |
| تفاصيل حلقات "Boruto" (293 حلقة) وصيغة الحلقات | صالح |
| فك تشفير CDN أولي (google.php→v-qs.php→RNCryptor) | يعيد 3 روابط MP4 مباشرة |
| تحميل أحد روابط MP4 بRange 1KB | `video/mp4` 200 مع ترويسة `ftypmp42` |
| الحصول على روابط المجموعات (`/api/f`) | صالح (OK.ru، MediaFire…) |
| استعلام بدون نتائج ورسائل خطأ HTTP | مغطاة نصياً بالعربية |

ملاحظات على الاختبار غير القابل لهذه البيئة:
- تشغيل ماحق على محاكي/جهاز فعلي غير متاح في بيئة التطوير (رمز كثيف Termux بلا SDK كامل)، لكن مسار الشبكة والمشغل والميزات تُبنى عليه نفس الطلبات التي أُجريت يدوياً بنجاح، مغطاة بمستودع CI (وحدة اختبارات + تحقق البناء).
- فك CDN قد يعمل على أي IP حي (تدقيق الرموز قصيرة العمر). التطبيق يتحقق من الرابط قبل عرضه، وإذا فشل يحاول التالي تلقائياً.
